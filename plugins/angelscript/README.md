# AngelScript skill

Teaches an AI agent to write and check AngelScript (`.as`) scripts that run inside a host application: the language traps, the engine rules file, the host API stubs and a check-after-every-edit workflow.

The skill drives the `angelscript_*` tools of [angelscript-mcp](https://github.com/angelscript-tools/angelscript-mcp). Install that server too, or the skill falls back to `asc --check` for scripts that do not call the host.

Source, install commands for other agents and the changelog: [angelscript-agent-kit](https://github.com/angelscript-tools/angelscript-agent-kit).
